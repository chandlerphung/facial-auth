# Facial Authentication Project

This project implements a **facial authentication system** in Python. It allows capturing user images, detecting faces, recognizing individuals, and interacting through a simple GUI interface.

---

## Features

- **Capture module:** Take pictures of users to build a dataset.
- **Detection module:** Detect faces in images using OpenCV.
- **Recognition module:** Recognize users from the captured dataset.
- **GUI module:** Simple graphical interface to interact with the system.

---

## Requirements

- Python 3.10+
- OpenCV
- NumPy
- Other dependencies can be installed via `requirements.txt`

To install dependencies:

```bash
pip install -r requirements.txt
```
